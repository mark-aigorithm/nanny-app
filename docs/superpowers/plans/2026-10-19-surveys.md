# Surveys Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Admins write surveys in the console, publish them to all mothers / groups / hand-picked mothers, see every answer, and resend to skipped or silent mothers; mothers are prompted in the app and answer or skip.

**Architecture:** Relational storage (survey → questions → options; recipient per mother → one answer row per question). Zod schemas and the answer-validation rule live once in `packages/shared`. Backend routes follow the existing inline-handler + service pattern; admin pages follow the Users/Campaigns pages; the mobile prompt is modelled on `RatingPromptHost`.

**Tech Stack:** Prisma 7 + PostgreSQL, Express, Zod 3, React + React Query + React Router 7 (admin), Expo Router + React Query + zustand (mobile), Jest / Vitest / MSW / RNTL.

**Spec:** `docs/superpowers/specs/2026-10-19-surveys-design.md`

## Global Constraints

- Mothers only (`Role.MOTHER`). Nannies never receive, see or answer surveys.
- Question types exactly: `TEXT`, `SINGLE_CHOICE`, `MULTI_CHOICE`, `RATING` (1–5), `YES_NO`.
- Survey status `DRAFT → PUBLISHED → CLOSED`; only `DRAFT` is editable or deletable. Duplicate works from any status.
- Recipient status `PENDING | SKIPPED | ANSWERED`; "didn't respond" = `PENDING`. `ANSWERED` recipients are never resent. Submitted answers are final.
- Skip keeps the survey in the mother's profile list; resend sets the status back to `PENDING`.
- Recipient list is frozen at publish; "Add recipients" adds more later.
- Picker metrics count `COMPLETED` bookings only.
- Backend conventions (`apps/backend/CLAUDE.md`): every model has `createdAt` / `updatedAt` / `deletedAt`; **soft delete only**; `Int @id @default(autoincrement())` (as every existing model does); snake_case columns via `@map`, plural snake_case tables via `@@map`, enums `@@map("snake_name")`; every query filters `deletedAt: null`; no `process.env`; no business logic in routes.
- Every admin route gets a row in `ADMIN_ROUTE_PERMISSIONS`. Survey routes: `GET` → `section('surveys','VIEW')`, else `section('surveys','MANAGE')`. Group routes use their own `groups` section; the two reads a survey publish needs (`GET /groups`, `GET /mother-picker`) also accept `surveys` MANAGE. Never a per-route check.
- **Groups are a standalone admin section and sidebar page (`/groups`)**, not part of Surveys, so a future notification center reuses them. Group code (shared `user-group.ts`, `admin-group.service.ts`, `mother-picker.service.ts`, admin `features/groups/`) must not import anything survey-specific; survey code may import group code, never the reverse.
- No `any`. `import type` for type-only imports. Files kebab-case (backend/admin), PascalCase screen/component files (mobile, matching the existing mobile tree).
- Admin UI follows the `nanny-app-admin-design` skill; mobile UI follows `nanny-app-mobile-design` and the "Rules from the UI sweep" in `apps/mobile/CLAUDE.md`. Load the skill before writing UI in those tasks.
- Long-running commands (test stack, integration suites, emulator, Metro) run in tmux: `tmux new -d -s nanny-<task> "<cmd> 2>&1 | tee ~/logs/nanny-<task>.log"`.

## Review Focus

1. **Two admins / double clicks on Publish** — the second publish must 409, never create duplicate recipients or send a second round of pushes. (Task 6 test: "publishing twice is refused".)
2. **A mother submits twice (double tap, retry after timeout)** — the second submit must 409 and leave exactly one set of answers. (Task 7 test: "a second submission is refused and answers are not duplicated".)
3. **Survey closed while she has the answer screen open** — submit and skip return 409 "This survey has closed." and the app shows the closed state, not a generic error. (Task 7/8 tests + Task 15 screen test.)
4. **Resend to "selected" includes a mother who already answered** — she must be left alone (no status reset, no push). (Task 8 test: "resend to selected skips answered mothers".)
5. **Deleted / suspended mothers and deleted groups** — never targeted by "All mothers" or by a group, and a group deleted after being picked fails the publish with a clear 400 rather than silently sending to nobody. (Task 6 tests: "skips suspended mothers", "refuses a deleted group".)

```ts
import { z } from 'zod';

import { AdminListQuerySchema, AdminSortDirSchema } from './admin';

// ──────────────────────────────────────────────────────────────
// Surveys — admin-written questionnaires sent to mothers. A survey is
// edited as a DRAFT, locked when PUBLISHED, and CLOSED to stop answers.
// Each mother it was sent to has one recipient row (PENDING / SKIPPED /
// ANSWERED) and, once she submits, one answer per question.
// ──────────────────────────────────────────────────────────────

export const SURVEY_TITLE_MAX = 120;
export const SURVEY_DESCRIPTION_MAX = 500;
export const SURVEY_PROMPT_MAX = 300;
export const SURVEY_OPTION_MAX = 120;
export const SURVEY_TEXT_ANSWER_MAX = 2000;
export const SURVEY_MAX_QUESTIONS = 30;
export const SURVEY_MAX_OPTIONS = 10;
/** Upper bound on one targeting / resend call, so a body can't be unbounded. */
export const SURVEY_MAX_USER_IDS = 5000;

export const SurveyStatusSchema = z.enum(['DRAFT', 'PUBLISHED', 'CLOSED']);
export type SurveyStatus = z.infer<typeof SurveyStatusSchema>;

export const SurveyQuestionTypeSchema = z.enum(['TEXT', 'SINGLE_CHOICE', 'MULTI_CHOICE', 'RATING', 'YES_NO']);
export type SurveyQuestionType = z.infer<typeof SurveyQuestionTypeSchema>;

export const SurveyRecipientStatusSchema = z.enum(['PENDING', 'SKIPPED', 'ANSWERED']);
export type SurveyRecipientStatus = z.infer<typeof SurveyRecipientStatusSchema>;

export function isChoiceQuestion(type: SurveyQuestionType): boolean {
  return type === 'SINGLE_CHOICE' || type === 'MULTI_CHOICE';
}

/** Blank strings are stored as null rather than as ''. */
const optionalText = (max: number) =>
  z.string().trim().max(max).nullish().transform((v) => (v ? v : null));

// ── Draft editing (admin) ──────────────────────────────────────

export const SurveyQuestionDraftSchema = z
  .object({
    type: SurveyQuestionTypeSchema,
    prompt: z.string().trim().min(1).max(SURVEY_PROMPT_MAX),
    required: z.boolean().default(true),
    options: z.array(z.string().trim().min(1).max(SURVEY_OPTION_MAX)).max(SURVEY_MAX_OPTIONS).default([]),
  })
  .superRefine((q, ctx) => {
    if (isChoiceQuestion(q.type)) {
      if (q.options.length < 2) {
        ctx.addIssue({ code: 'custom', path: ['options'], message: 'A choice question needs at least 2 options.' });
      }
      if (new Set(q.options.map((o) => o.toLowerCase())).size !== q.options.length) {
        ctx.addIssue({ code: 'custom', path: ['options'], message: 'Options must be different from each other.' });
      }
    } else if (q.options.length > 0) {
      ctx.addIssue({ code: 'custom', path: ['options'], message: 'Only choice questions have options.' });
    }
  });

/** Create and PATCH both send the whole draft; PATCH replaces every question. */
export const SurveyDraftSchema = z.object({
  title: z.string().trim().min(1).max(SURVEY_TITLE_MAX),
  description: optionalText(SURVEY_DESCRIPTION_MAX),
  questions: z.array(SurveyQuestionDraftSchema).max(SURVEY_MAX_QUESTIONS).default([]),
});
export type SurveyDraftInput = z.input<typeof SurveyDraftSchema>;
export type SurveyDraft = z.output<typeof SurveyDraftSchema>;

// ── Sending ────────────────────────────────────────────────────

const UserIdListSchema = z.array(z.number().int().positive()).max(SURVEY_MAX_USER_IDS);

/** Who a publish / "add recipients" reaches. The three are unioned and deduplicated. */
export const SurveyTargetSchema = z
  .object({
    allMothers: z.boolean().default(false),
    groupIds: z.array(z.number().int().positive()).max(100).default([]),
    userIds: UserIdListSchema.default([]),
  })
  .refine((t) => t.allMothers || t.groupIds.length > 0 || t.userIds.length > 0, {
    message: 'Choose who to send the survey to.',
  });
export type SurveyTargetInput = z.input<typeof SurveyTargetSchema>;
export type SurveyTarget = z.output<typeof SurveyTargetSchema>;

/** Resend to chosen mothers, or to everyone who skipped / never responded. */
export const SurveyResendSchema = z.union([
  z.object({ userIds: UserIdListSchema.min(1) }).strict(),
  z.object({ status: z.enum(['SKIPPED', 'PENDING']) }).strict(),
]);
export type SurveyResendInput = z.infer<typeof SurveyResendSchema>;

export const SurveySendResultSchema = z.object({ count: z.number().int() });
export type SurveySendResult = z.infer<typeof SurveySendResultSchema>;

// ── Read models ────────────────────────────────────────────────

export const SurveyOptionSchema = z.object({
  id: z.number().int(),
  order: z.number().int(),
  label: z.string(),
});
export type SurveyOption = z.infer<typeof SurveyOptionSchema>;

export const SurveyQuestionSchema = z.object({
  id: z.number().int(),
  order: z.number().int(),
  type: SurveyQuestionTypeSchema,
  prompt: z.string(),
  required: z.boolean(),
  options: z.array(SurveyOptionSchema),
});
export type SurveyQuestion = z.infer<typeof SurveyQuestionSchema>;

export const SurveyCountsSchema = z.object({
  recipients: z.number().int(),
  answered: z.number().int(),
  skipped: z.number().int(),
  pending: z.number().int(),
});
export type SurveyCounts = z.infer<typeof SurveyCountsSchema>;

export const AdminSurveySummarySchema = z.object({
  id: z.number().int(),
  title: z.string(),
  status: SurveyStatusSchema,
  counts: SurveyCountsSchema,
  publishedAt: z.string().nullable(),
  closedAt: z.string().nullable(),
  createdAt: z.string(),
});
export type AdminSurveySummary = z.infer<typeof AdminSurveySummarySchema>;

export const AdminSurveySchema = AdminSurveySummarySchema.extend({
  description: z.string().nullable(),
  questions: z.array(SurveyQuestionSchema),
});
export type AdminSurvey = z.infer<typeof AdminSurveySchema>;

export const AdminSurveyListQuerySchema = AdminListQuerySchema.extend({
  status: SurveyStatusSchema.optional().catch(undefined),
});
export type AdminSurveyListQuery = z.infer<typeof AdminSurveyListQuerySchema>;

export const ADMIN_SURVEY_RECIPIENT_SORT_KEYS = ['name', 'status', 'sentCount', 'lastSentAt', 'answeredAt'] as const;
export const AdminSurveyRecipientSortKeySchema = z.enum(ADMIN_SURVEY_RECIPIENT_SORT_KEYS);
export type AdminSurveyRecipientSortKey = z.infer<typeof AdminSurveyRecipientSortKeySchema>;

export const AdminSurveyRecipientListQuerySchema = AdminListQuerySchema.extend({
  status: SurveyRecipientStatusSchema.optional().catch(undefined),
  sortBy: AdminSurveyRecipientSortKeySchema.catch('lastSentAt').default('lastSentAt'),
  sortDir: AdminSortDirSchema.catch('desc').default('desc'),
});
export type AdminSurveyRecipientListQuery = z.infer<typeof AdminSurveyRecipientListQuerySchema>;

export const AdminSurveyRecipientSchema = z.object({
  userId: z.number().int(),
  name: z.string(),
  phone: z.string().nullable(),
  status: SurveyRecipientStatusSchema,
  sentCount: z.number().int(),
  lastSentAt: z.string(),
  skippedAt: z.string().nullable(),
  answeredAt: z.string().nullable(),
});
export type AdminSurveyRecipient = z.infer<typeof AdminSurveyRecipientSchema>;

/** One stored answer; exactly one value field is set, matching the question's type. */
export const SurveyAnswerSchema = z.object({
  questionId: z.number().int(),
  text: z.string().nullable(),
  rating: z.number().int().nullable(),
  bool: z.boolean().nullable(),
  optionIds: z.array(z.number().int()),
});
export type SurveyAnswer = z.infer<typeof SurveyAnswerSchema>;

export const AdminSurveyRecipientAnswersSchema = z.object({
  recipient: AdminSurveyRecipientSchema,
  answers: z.array(SurveyAnswerSchema),
});
export type AdminSurveyRecipientAnswers = z.infer<typeof AdminSurveyRecipientAnswersSchema>;

// ── Results ────────────────────────────────────────────────────

export const SurveyOptionResultSchema = z.object({
  optionId: z.number().int(),
  label: z.string(),
  count: z.number().int(),
});
export type SurveyOptionResult = z.infer<typeof SurveyOptionResultSchema>;

export const SurveyQuestionResultSchema = z.object({
  questionId: z.number().int(),
  order: z.number().int(),
  type: SurveyQuestionTypeSchema,
  prompt: z.string(),
  required: z.boolean(),
  /** Mothers who gave this question a value. */
  answeredCount: z.number().int(),
  /** Choice questions only; [] otherwise. */
  options: z.array(SurveyOptionResultSchema),

// ── The answer rule — one copy, used by the backend to refuse and the app to enable Submit ──

type ValueField = 'text' | 'rating' | 'bool' | 'optionIds';

function valueFieldFor(type: SurveyQuestionType): ValueField {
  switch (type) {
    case 'TEXT':
      return 'text';
    case 'RATING':
      return 'rating';
    case 'YES_NO':
      return 'bool';
    case 'SINGLE_CHOICE':
    case 'MULTI_CHOICE':
      return 'optionIds';
  }
}

/** Whether an answer carries a real value for its type. Blank text and no picks are not answers. */
export function hasAnswerValue(type: SurveyQuestionType, answer: SurveyAnswerInput | undefined): boolean {
  if (!answer) return false;
  switch (valueFieldFor(type)) {
    case 'text':
      return (answer.text?.trim().length ?? 0) > 0;
    case 'rating':
      return answer.rating !== undefined;
    case 'bool':
      return answer.bool !== undefined;
    case 'optionIds':
      return (answer.optionIds?.length ?? 0) > 0;
  }
}

type QuestionForCheck = Pick<SurveyQuestion, 'id' | 'type' | 'prompt' | 'required'> & {
  options: Pick<SurveyOption, 'id'>[];
};

/** Why a submission can't be accepted, or null when it can. */
export function findSurveyAnswerProblem(
  questions: QuestionForCheck[],
  answers: SurveyAnswerInput[],
): string | null {
  const byId = new Map(questions.map((q) => [q.id, q]));
  const seen = new Set<number>();

  for (const answer of answers) {
    const question = byId.get(answer.questionId);
    if (!question) return 'An answer refers to a question that is not in this survey.';
    if (seen.has(answer.questionId)) return 'A question was answered twice.';
    seen.add(answer.questionId);

    const given = (['text', 'rating', 'bool', 'optionIds'] as const).filter((f) => answer[f] !== undefined);
    const expected = valueFieldFor(question.type);
    if (given.length > 1 || (given.length === 1 && given[0] !== expected)) {
      return `"${question.prompt}" got the wrong kind of answer.`;
    }

    if (answer.optionIds) {
      const valid = new Set(question.options.map((o) => o.id));
      if (answer.optionIds.some((id) => !valid.has(id))) {
        return `"${question.prompt}" has an option that doesn't belong to it.`;
      }
      if (new Set(answer.optionIds).size !== answer.optionIds.length) {
        return `"${question.prompt}" has an option picked more than once.`;
      }
      if (question.type === 'SINGLE_CHOICE' && answer.optionIds.length > 1) {
        return `Pick one option for "${question.prompt}".`;
      }
    }
  }

  for (const question of questions) {
    if (!question.required) continue;
    const answer = answers.find((a) => a.questionId === question.id);
    if (!hasAnswerValue(question.type, answer)) return `"${question.prompt}" is required.`;
  }
  return null;
}
```

```ts
import { Role } from '@prisma/client';

import type { UserGroup, UserGroupInput } from '@nanny-app/shared';
import { UserGroupInputSchema } from '@nanny-app/shared';

import { prisma } from '@backend/db/prisma';
import { errors } from '@backend/lib/errors';

const withMemberCount = {
  _count: { select: { members: { where: { deletedAt: null } } } },
} as const;

type GroupRow = {
  id: number;
  name: string;
  description: string | null;
  createdAt: Date;
  _count: { members: number };
};

function toDto(row: GroupRow): UserGroup {
  return {
    id: row.id,
    name: row.name,
    description: row.description,
    memberCount: row._count.members,
    createdAt: row.createdAt.toISOString(),
  };
}

async function requireGroup(id: number): Promise<GroupRow> {
  const row = await prisma.userGroup.findFirst({ where: { id, deletedAt: null }, include: withMemberCount });
  if (!row) throw errors.notFound('Group not found.');
  return row;
}

/** Names are unique among live groups, ignoring case. */
async function assertNameFree(name: string, exceptId?: number): Promise<void> {
  const clash = await prisma.userGroup.findFirst({
    where: {
      name: { equals: name, mode: 'insensitive' },
      deletedAt: null,
      ...(exceptId ? { id: { not: exceptId } } : {}),
    },
    select: { id: true },
  });
  if (clash) throw errors.conflict('A group with this name already exists.');
}

export async function listUserGroups(): Promise<UserGroup[]> {
  const rows = await prisma.userGroup.findMany({
    where: { deletedAt: null },
    include: withMemberCount,
    orderBy: { name: 'asc' },
  });
  return rows.map(toDto);
}

export async function getUserGroup(id: number): Promise<UserGroup> {
  return toDto(await requireGroup(id));
}

export async function createUserGroup(adminId: number, input: UserGroupInput): Promise<UserGroup> {
  const { name, description } = UserGroupInputSchema.parse(input);
  await assertNameFree(name);
  const row = await prisma.userGroup.create({
    data: { name, description, createdById: adminId },
    include: withMemberCount,
  });
  return toDto(row);
}

export async function updateUserGroup(id: number, input: UserGroupInput): Promise<UserGroup> {
  const { name, description } = UserGroupInputSchema.parse(input);
  await requireGroup(id);
  await assertNameFree(name, id);
  const row = await prisma.userGroup.update({
    where: { id },
    data: { name, description },
    include: withMemberCount,
  });
  return toDto(row);
}

export async function deleteUserGroup(id: number): Promise<void> {
  await requireGroup(id);
  await prisma.userGroup.update({ where: { id }, data: { deletedAt: new Date() } });
}

export async function addUserGroupMembers(id: number, userIds: number[]): Promise<UserGroup> {
  await requireGroup(id);
  const ids = [...new Set(userIds)];
  const mothers = await prisma.user.count({ where: { id: { in: ids }, role: Role.MOTHER, deletedAt: null } });
  if (mothers !== ids.length) throw errors.badRequest('Only mothers can be added to a group.');

  await prisma.$transaction([
    // Someone removed earlier comes back on the same row.
    prisma.userGroupMember.updateMany({
      where: { groupId: id, userId: { in: ids }, deletedAt: { not: null } },
      data: { deletedAt: null },
    }),
    prisma.userGroupMember.createMany({
      data: ids.map((userId) => ({ groupId: id, userId })),
      skipDuplicates: true,
    }),
  ]);
  return getUserGroup(id);
}

export async function removeUserGroupMembers(id: number, userIds: number[]): Promise<UserGroup> {
  await requireGroup(id);
  await prisma.userGroupMember.updateMany({
    where: { groupId: id, userId: { in: userIds }, deletedAt: null },
    data: { deletedAt: new Date() },
  });
  return getUserGroup(id);
}
```

```ts
import { Prisma } from '@prisma/client';

import type { MotherPickerQuery, MotherPickerRow, MotherPickerSortKey, PaginationMeta } from '@nanny-app/shared';

import { prisma } from '@backend/db/prisma';
import { displayName } from '@backend/lib/survey-dto';

// Sorting by an aggregate has to happen in the database, before LIMIT/OFFSET —
// sorting one fetched page would order only that page. Hence raw SQL: Prisma's
// query builder can't order users by a sum over their bookings.

const ORDER_BY: Record<MotherPickerSortKey, Prisma.Sql> = {
  name: Prisma.sql`lower(u.first_name || ' ' || u.last_name)`,
  completedBookings: Prisma.sql`completed_bookings`,
  hoursBooked: Prisma.sql`hours_booked`,
  totalSpent: Prisma.sql`total_spent`,
  lastBookingAt: Prisma.sql`last_booking_at`,
  createdAt: Prisma.sql`u.created_at`,
  lastLoginAt: Prisma.sql`u.last_login_at`,
};

type RawRow = {
  id: number;
  first_name: string;
  last_name: string;
  phone: string | null;
  created_at: Date;
  last_login_at: Date | null;
  completed_bookings: bigint;
  hours_booked: Prisma.Decimal;
  total_spent: Prisma.Decimal;
  last_booking_at: Date | null;
};

function escapeLike(term: string): string {
  return term.replace(/[\\%_]/g, (c) => `\\${c}`);
}

export async function listMotherPicker(
  q: MotherPickerQuery,
): Promise<{ rows: MotherPickerRow[]; meta: PaginationMeta }> {
  const conditions: Prisma.Sql[] = [Prisma.sql`u.role = 'MOTHER'`, Prisma.sql`u.deleted_at IS NULL`];
  if (q.search) {
    const like = `%${escapeLike(q.search)}%`;
    conditions.push(
      Prisma.sql`((u.first_name || ' ' || u.last_name) ILIKE ${like} OR u.phone ILIKE ${like} OR u.email ILIKE ${like})`,
    );
  }
  if (q.groupId) {
    conditions.push(Prisma.sql`EXISTS (
      SELECT 1 FROM user_group_members m JOIN user_groups g ON g.id = m.group_id
      WHERE m.user_id = u.id AND m.group_id = ${q.groupId}
        AND m.deleted_at IS NULL AND g.deleted_at IS NULL)`);
  }
  const where = Prisma.join(conditions, ' AND ');
  const dir = q.sortDir === 'asc' ? Prisma.sql`ASC` : Prisma.sql`DESC`;
  const offset = (q.page - 1) * q.limit;

  const [countRows, raw] = await Promise.all([
    prisma.$queryRaw<{ total: bigint }[]>`SELECT count(*) AS total FROM users u WHERE ${where}`,
    prisma.$queryRaw<RawRow[]>`
      SELECT u.id, u.first_name, u.last_name, u.phone, u.created_at, u.last_login_at,
             coalesce(b.completed_bookings, 0) AS completed_bookings,
             coalesce(b.hours_booked, 0) AS hours_booked,
             coalesce(b.total_spent, 0) AS total_spent,
             b.last_booking_at
      FROM users u
      LEFT JOIN (
        SELECT mother_id,
               count(*) AS completed_bookings,
               sum(duration_hours) AS hours_booked,
               sum(total_amount) AS total_spent,
               max(start_time) AS last_booking_at
        FROM bookings
        WHERE status = 'COMPLETED' AND deleted_at IS NULL
        GROUP BY mother_id
      ) b ON b.mother_id = u.id
      WHERE ${where}
      ORDER BY ${ORDER_BY[q.sortBy]} ${dir} NULLS LAST, u.id ASC
      LIMIT ${q.limit} OFFSET ${offset}`,
  ]);

  const total = Number(countRows[0]?.total ?? 0);
  return {
    rows: raw.map((r) => ({
      id: r.id,
      name: displayName(r.first_name, r.last_name),
      phone: r.phone,
      completedBookings: Number(r.completed_bookings),
      hoursBooked: Number(r.hours_booked),
      totalSpent: Number(r.total_spent),
      lastBookingAt: r.last_booking_at ? r.last_booking_at.toISOString() : null,
      createdAt: r.created_at.toISOString(),
      lastLoginAt: r.last_login_at ? r.last_login_at.toISOString() : null,
    })),
    meta: { page: q.page, limit: q.limit, total, totalPages: Math.max(1, Math.ceil(total / q.limit)) },
  };
}
```

If Postgres rejects `ORDER BY completed_bookings` combined with `NULLS LAST` because the alias is used in an expression, it isn't — a bare output-column alias is allowed; the `name` key is an expression over table columns, which is also allowed. If the role comparison errors on the enum type, cast it: `u.role = 'MOTHER'::"Role"` (check the enum's DB name in the init migration).

```ts
export async function surveyCounts(surveyIds: number[]): Promise<Map<number, SurveyCounts>> {
  const map = new Map<number, SurveyCounts>();
  if (surveyIds.length === 0) return map;
  const grouped = await prisma.surveyRecipient.groupBy({
    by: ['surveyId', 'status'],
    where: { surveyId: { in: surveyIds }, deletedAt: null },
    _count: { _all: true },
  });
  for (const g of grouped) {
    const counts = map.get(g.surveyId) ?? { ...EMPTY_COUNTS };
    const n = g._count._all;
    counts.recipients += n;
    if (g.status === 'ANSWERED') counts.answered += n;
    if (g.status === 'SKIPPED') counts.skipped += n;
    if (g.status === 'PENDING') counts.pending += n;
    map.set(g.surveyId, counts);
  }
  return map;
}
```

```ts
import { Role, type Prisma } from '@prisma/client';

import type { SurveyTarget } from '@nanny-app/shared';

import { prisma } from '@backend/db/prisma';
import { errors } from '@backend/lib/errors';
import { createInAppNotifications, dispatchPush } from '@backend/services/notification.service';

export const SURVEY_PUSH_TITLE = "We'd love your feedback";

/**
 * Pushes go out a few at a time inside the request: the backend runs on Vercel
 * with no background worker. Fine for hundreds of mothers; thousands need the
 * planned queue (see the spec's known limit).
 */
const PUSH_BATCH = 25;

/** A mother who can receive a survey. */
const receivable: Prisma.UserWhereInput = { role: Role.MOTHER, deletedAt: null, isActive: true };

/** The union of the target's mothers, deduplicated and sorted. */
export async function resolveSurveyAudience(target: SurveyTarget): Promise<number[]> {
  const groupIds = [...new Set(target.groupIds)];
  const userIds = [...new Set(target.userIds)];

  if (groupIds.length > 0) {
    const live = await prisma.userGroup.count({ where: { id: { in: groupIds }, deletedAt: null } });
    if (live !== groupIds.length) throw errors.badRequest('One of the chosen groups no longer exists.');
  }
  if (userIds.length > 0) {
    const ok = await prisma.user.count({ where: { id: { in: userIds }, ...receivable } });
    if (ok !== userIds.length) {
      throw errors.badRequest("Some of the chosen people can't receive surveys — only active mothers can.");
    }
  }

  const where: Prisma.UserWhereInput = target.allMothers
    ? receivable
    : {
        ...receivable,
        OR: [
          { id: { in: userIds } },
          { userGroupMemberships: { some: { groupId: { in: groupIds }, deletedAt: null } } },
        ],
      };
  const rows = await prisma.user.findMany({ where, select: { id: true }, orderBy: { id: 'asc' } });
  return rows.map((r) => r.id);
}

/** In-app notification for every recipient, then a push each, in batches. */
export async function notifySurveyRecipients(
  survey: { id: number; title: string },
  userIds: number[],
): Promise<void> {
  if (userIds.length === 0) return;
  await createInAppNotifications(
    userIds.map((userId) => ({
      userId,
      type: 'SURVEY',
      title: SURVEY_PUSH_TITLE,
      body: survey.title,
      referenceId: survey.id,
      referenceType: 'SURVEY',
    })),
  );
  const data = { type: 'SURVEY', surveyId: String(survey.id) };
  for (let i = 0; i < userIds.length; i += PUSH_BATCH) {
    await Promise.all(
      userIds.slice(i, i + PUSH_BATCH).map((userId) =>
        dispatchPush(userId, { title: SURVEY_PUSH_TITLE, body: survey.title, data }),
      ),
    );
  }
}
```

```ts
import type { SurveySendResult, SurveyTarget } from '@nanny-app/shared';
import { notifySurveyRecipients, resolveSurveyAudience } from '@backend/services/survey-audience.service';

export async function publishSurvey(id: number, target: SurveyTarget): Promise<SurveySendResult> {
  const survey = await requireSurvey(id);
  assertDraft(survey);
  if (survey.questions.length === 0) throw errors.badRequest('Add at least one question before publishing.');
  const userIds = await resolveSurveyAudience(target);
  if (userIds.length === 0) throw errors.badRequest('No mothers match this selection.');

  const now = new Date();
  await prisma.$transaction(async (tx) => {
    // The status guard makes a second, concurrent publish lose instead of
    // sending the survey twice.
    const { count } = await tx.survey.updateMany({
      where: { id, status: SurveyStatus.DRAFT, deletedAt: null },
      data: { status: SurveyStatus.PUBLISHED, publishedAt: now },
    });
    if (count === 0) throw errors.conflict('This survey has already been published.');
    await tx.surveyRecipient.createMany({
      data: userIds.map((userId) => ({ surveyId: id, userId, lastSentAt: now })),
      skipDuplicates: true,
    });
  });

  await notifySurveyRecipients(survey, userIds);
  return { count: userIds.length };
}

function assertPublished(row: { status: SurveyStatus }, action: string): void {
  if (row.status !== SurveyStatus.PUBLISHED) {
    throw errors.conflict(`Only a published survey can ${action}.`);
  }
}

export async function addSurveyRecipients(id: number, target: SurveyTarget): Promise<SurveySendResult> {
  const survey = await requireSurvey(id);
  assertPublished(survey, 'take more recipients');
  const audience = await resolveSurveyAudience(target);
  const existing = await prisma.surveyRecipient.findMany({
    where: { surveyId: id, userId: { in: audience } },
    select: { userId: true },
  });
  const already = new Set(existing.map((r) => r.userId));
  const fresh = audience.filter((userId) => !already.has(userId));
  if (fresh.length === 0) return { count: 0 };

  const now = new Date();
  await prisma.surveyRecipient.createMany({
    data: fresh.map((userId) => ({ surveyId: id, userId, lastSentAt: now })),
    skipDuplicates: true,
  });
  await notifySurveyRecipients(survey, fresh);
  return { count: fresh.length };
}
```

```ts
import { Role, SurveyRecipientStatus, SurveyStatus, type User } from '@prisma/client';
import type { DecodedIdToken } from 'firebase-admin/auth';

import type { MotherSurvey, MotherSurveySummary, SubmitSurveyAnswersInput } from '@nanny-app/shared';
import { findSurveyAnswerProblem, hasAnswerValue } from '@nanny-app/shared';

import { prisma } from '@backend/db/prisma';
import { errors } from '@backend/lib/errors';
import { surveyQuestionsInclude, toQuestionDto } from '@backend/lib/survey-dto';

const OPEN_STATUSES = [SurveyRecipientStatus.PENDING, SurveyRecipientStatus.SKIPPED];

async function requireMother(decoded: DecodedIdToken): Promise<User> {
  const user = await prisma.user.findUnique({ where: { firebaseUid: decoded.uid } });
  if (!user || user.deletedAt) {
    throw errors.notFound('User profile not found. Please complete registration.');
  }
  if (user.role !== Role.MOTHER) throw errors.forbidden('Only mothers can answer surveys.');
  return user;
}

/** Her recipient row on a survey she can still act on, with the survey's questions. */
async function requireOpenRecipient(userId: number, surveyId: number) {
  const recipient = await prisma.surveyRecipient.findFirst({
    where: { surveyId, userId, deletedAt: null, survey: { deletedAt: null, status: { not: SurveyStatus.DRAFT } } },
    include: { survey: { include: surveyQuestionsInclude } },
  });
  if (!recipient) throw errors.notFound('Survey not found.');
  if (recipient.survey.status === SurveyStatus.CLOSED) throw errors.conflict('This survey has closed.');
  if (recipient.status === SurveyRecipientStatus.ANSWERED) {
    throw errors.conflict('You have already answered this survey.');
  }
  return recipient;
}

/** PENDING and SKIPPED surveys on published surveys — the prompt and the profile list. Oldest send first. */
export async function listMyPendingSurveys(decoded: DecodedIdToken): Promise<MotherSurveySummary[]> {
  const user = await requireMother(decoded);
  const rows = await prisma.surveyRecipient.findMany({
    where: {
      userId: user.id,
      deletedAt: null,
      status: { in: OPEN_STATUSES },
      survey: { status: SurveyStatus.PUBLISHED, deletedAt: null },
    },
    include: {
      survey: { include: { _count: { select: { questions: { where: { deletedAt: null } } } } } },
    },
    orderBy: { lastSentAt: 'asc' },
  });
  return rows.map((r) => ({
    id: r.survey.id,
    title: r.survey.title,
    description: r.survey.description,
    status: r.status === SurveyRecipientStatus.SKIPPED ? 'SKIPPED' : 'PENDING',
    questionCount: r.survey._count.questions,
    lastSentAt: r.lastSentAt.toISOString(),
  }));
}

export async function getMySurvey(decoded: DecodedIdToken, surveyId: number): Promise<MotherSurvey> {
  const user = await requireMother(decoded);
  const { survey } = await requireOpenRecipient(user.id, surveyId);
  return {
    id: survey.id,
    title: survey.title,
    description: survey.description,
    questions: survey.questions.map(toQuestionDto),
  };
}

export async function skipMySurvey(decoded: DecodedIdToken, surveyId: number): Promise<void> {
  const user = await requireMother(decoded);
  const recipient = await requireOpenRecipient(user.id, surveyId);
  if (recipient.status === SurveyRecipientStatus.SKIPPED) return;
  await prisma.surveyRecipient.update({
    where: { id: recipient.id },
    data: { status: SurveyRecipientStatus.SKIPPED, skippedAt: new Date() },
  });
}

export async function submitMySurveyAnswers(
  decoded: DecodedIdToken,
  surveyId: number,
  input: SubmitSurveyAnswersInput,
): Promise<void> {
  const user = await requireMother(decoded);
  const recipient = await requireOpenRecipient(user.id, surveyId);
  const questions = recipient.survey.questions;

  const problem = findSurveyAnswerProblem(questions, input.answers);
  if (problem) throw errors.badRequest(problem);

  const typeOf = new Map(questions.map((q) => [q.id, q.type]));
  const given = input.answers.filter((a) => hasAnswerValue(typeOf.get(a.questionId)!, a));

  await prisma.$transaction(async (tx) => {
    // Status guard: of two concurrent submits, only one flips the row.
    const { count } = await tx.surveyRecipient.updateMany({
      where: { id: recipient.id, status: { in: OPEN_STATUSES } },
      data: { status: SurveyRecipientStatus.ANSWERED, answeredAt: new Date() },
    });
    if (count === 0) throw errors.conflict('You have already answered this survey.');

    for (const answer of given) {
      await tx.surveyAnswer.create({
        data: {
          recipientId: recipient.id,
          questionId: answer.questionId,
          textValue: answer.text?.trim() ?? null,
          ratingValue: answer.rating ?? null,
          boolValue: answer.bool ?? null,
          ...(answer.optionIds ? { options: { create: answer.optionIds.map((optionId) => ({ optionId })) } } : {}),
        },
      });
    }
  });
}
```

```ts
import type { SurveyResendInput } from '@nanny-app/shared';

export async function resendSurvey(id: number, body: SurveyResendInput): Promise<SurveySendResult> {
  const survey = await requireSurvey(id);
  assertPublished(survey, 'be resent');

  const where =
    'userIds' in body
      ? { surveyId: id, deletedAt: null, userId: { in: body.userIds }, status: { not: SurveyRecipientStatus.ANSWERED } }
      : { surveyId: id, deletedAt: null, status: body.status };
  const targets = await prisma.surveyRecipient.findMany({ where, select: { id: true, userId: true } });
  if (targets.length === 0) return { count: 0 };

  await prisma.surveyRecipient.updateMany({
    where: { id: { in: targets.map((t) => t.id) }, status: { not: SurveyRecipientStatus.ANSWERED } },
    data: { status: SurveyRecipientStatus.PENDING, sentCount: { increment: 1 }, lastSentAt: new Date() },
  });
  await notifySurveyRecipients(survey, targets.map((t) => t.userId));
  return { count: targets.length };
}
```

```ts
const meta = (page: number, limit: number, total: number): PaginationMeta => ({
  page,
  limit,
  total,
  totalPages: Math.max(1, Math.ceil(total / limit)),
});

export async function getSurveyResults(id: number): Promise<SurveyResults> {
  const survey = await requireSurvey(id);
  const live = { deletedAt: null, question: { surveyId: id } };

  const [answered, ratings, bools, picks, counts] = await Promise.all([
    prisma.surveyAnswer.groupBy({ by: ['questionId'], where: live, _count: { _all: true } }),
    prisma.surveyAnswer.groupBy({
      by: ['questionId', 'ratingValue'],
      where: { ...live, ratingValue: { not: null } },
      _count: { _all: true },
    }),
    prisma.surveyAnswer.groupBy({
      by: ['questionId', 'boolValue'],
      where: { ...live, boolValue: { not: null } },
      _count: { _all: true },
    }),
    prisma.surveyAnswerOption.groupBy({
      by: ['optionId'],
      where: { deletedAt: null, answer: { deletedAt: null, question: { surveyId: id } } },
      _count: { _all: true },
    }),
    surveyCounts([id]),
  ]);

  const answeredBy = new Map(answered.map((g) => [g.questionId, g._count._all]));
  const pickCount = new Map(picks.map((g) => [g.optionId, g._count._all]));

  const questions: SurveyQuestionResult[] = survey.questions.map((q) => {
    const base: SurveyQuestionResult = {
      questionId: q.id,
      order: q.order,
      type: q.type,
      prompt: q.prompt,
      required: q.required,
      answeredCount: answeredBy.get(q.id) ?? 0,
      options: [],
      yesCount: null,
      noCount: null,
      ratingCounts: null,
      ratingAverage: null,
    };
    if (q.type === 'SINGLE_CHOICE' || q.type === 'MULTI_CHOICE') {
      base.options = q.options.map((o) => ({ optionId: o.id, label: o.label, count: pickCount.get(o.id) ?? 0 }));
    }
    if (q.type === 'YES_NO') {
      const mine = bools.filter((g) => g.questionId === q.id);
      base.yesCount = mine.find((g) => g.boolValue === true)?._count._all ?? 0;
      base.noCount = mine.find((g) => g.boolValue === false)?._count._all ?? 0;
    }
    if (q.type === 'RATING') {
      const spread = [0, 0, 0, 0, 0];
      for (const g of ratings.filter((r) => r.questionId === q.id)) {
        if (g.ratingValue != null) spread[g.ratingValue - 1] = g._count._all;
      }
      const total = spread.reduce((s, n) => s + n, 0);
      base.ratingCounts = spread;
      base.ratingAverage = total === 0 ? null : spread.reduce((s, n, i) => s + n * (i + 1), 0) / total;
    }
    return base;
  });

  return { surveyId: id, counts: counts.get(id) ?? { ...EMPTY_COUNTS }, questions };
}

export async function listSurveyTextAnswers(
  id: number,
  q: SurveyTextAnswerQuery,
): Promise<{ answers: SurveyTextAnswer[]; meta: PaginationMeta }> {
  await requireSurvey(id);
  const where: Prisma.SurveyAnswerWhereInput = {
    deletedAt: null,
    questionId: q.questionId,
    question: { surveyId: id },
    textValue: { not: null },
  };
  const [total, rows] = await prisma.$transaction([
    prisma.surveyAnswer.count({ where }),
    prisma.surveyAnswer.findMany({
      where,
      include: { recipient: { include: { user: { select: { id: true, firstName: true, lastName: true } } } } },
      orderBy: { createdAt: 'desc' },
      skip: (q.page - 1) * q.limit,
      take: q.limit,
    }),
  ]);
  return {
    answers: rows.map((r) => ({
      userId: r.recipient.user.id,
      name: displayName(r.recipient.user.firstName, r.recipient.user.lastName),
      text: r.textValue ?? '',
      answeredAt: r.createdAt.toISOString(),
    })),
    meta: meta(q.page, q.limit, total),
  };
}

const recipientInclude = {
  user: { select: { id: true, firstName: true, lastName: true, phone: true } },
} as const;

type RecipientRow = Prisma.SurveyRecipientGetPayload<{ include: typeof recipientInclude }>;

function toRecipientDto(r: RecipientRow): AdminSurveyRecipient {
  return {
    userId: r.user.id,
    name: displayName(r.user.firstName, r.user.lastName),
    phone: r.user.phone,
    status: r.status,
    sentCount: r.sentCount,
    lastSentAt: r.lastSentAt.toISOString(),
    skippedAt: r.skippedAt ? r.skippedAt.toISOString() : null,
    answeredAt: r.answeredAt ? r.answeredAt.toISOString() : null,
  };
}

function recipientOrderBy(q: AdminSurveyRecipientListQuery): Prisma.SurveyRecipientOrderByWithRelationInput[] {
  const dir = q.sortDir;
  switch (q.sortBy) {
    case 'name':
      return [{ user: { firstName: dir } }, { user: { lastName: dir } }];
    case 'status':
      return [{ status: dir }];
    case 'sentCount':
      return [{ sentCount: dir }];
    case 'answeredAt':
      return [{ answeredAt: { sort: dir, nulls: 'last' } }];
    case 'lastSentAt':
      return [{ lastSentAt: dir }];
  }
}

export async function listSurveyRecipients(
  id: number,
  q: AdminSurveyRecipientListQuery,
): Promise<{ recipients: AdminSurveyRecipient[]; meta: PaginationMeta }> {
  await requireSurvey(id);
  const where: Prisma.SurveyRecipientWhereInput = { surveyId: id, deletedAt: null, ...(q.status ? { status: q.status } : {}) };
  const [total, rows] = await prisma.$transaction([
    prisma.surveyRecipient.count({ where }),
    prisma.surveyRecipient.findMany({
      where,
      include: recipientInclude,
      orderBy: [...recipientOrderBy(q), { id: 'asc' }],
      skip: (q.page - 1) * q.limit,
      take: q.limit,
    }),
  ]);
  return { recipients: rows.map(toRecipientDto), meta: meta(q.page, q.limit, total) };
}

export async function getSurveyRecipientAnswers(id: number, userId: number): Promise<AdminSurveyRecipientAnswers> {
  await requireSurvey(id);
  const row = await prisma.surveyRecipient.findFirst({
    where: { surveyId: id, userId, deletedAt: null },
    include: {
      ...recipientInclude,
      answers: { where: { deletedAt: null }, include: { options: { where: { deletedAt: null } } } },
    },
  });
  if (!row) throw errors.notFound('This mother was not sent this survey.');
  return {
    recipient: toRecipientDto(row),
    answers: row.answers.map((a) => ({
      questionId: a.questionId,
      text: a.textValue,
      rating: a.ratingValue,
      bool: a.boolValue,
      optionIds: a.options.map((o) => o.optionId),
    })),
  };
}
```

```tsx
import type { MotherPickerRow, MotherPickerSortKey } from '@nanny-app/shared';
import { ADMIN_PAGE_SIZES } from '@nanny-app/shared';
import { keepPreviousData, useQuery } from '@tanstack/react-query';
import { useEffect, useState } from 'react';

import { ErrorState, Input, Pagination, Table, TableSkeleton, type Column } from '@admin/components/ui';
import { fetchMotherPicker } from '@admin/lib/api';
import { usePagination } from '@admin/lib/use-pagination';
import { useTableSort } from '@admin/lib/use-table-sort';

type Props = {
  selected: ReadonlySet<number>;
  onSelectedChange: (next: Set<number>) => void;
  /** List only this group's members. */
  groupId?: number;
};

const day = (iso: string | null) => (iso ? new Date(iso).toLocaleDateString() : '—');
const money = (n: number) => n.toLocaleString(undefined, { maximumFractionDigits: 0 });

/**
 * Mothers with their booking activity, sorted by the API (aggregates are
 * computed before paging). Bookings, hours and spend count completed bookings
 * only. The parent owns the selection, so ticks survive paging and searching.
 */
export function MotherPickerTable({ selected, onSelectedChange, groupId }: Props) {
  const { page, limit, setPage, setLimit } = usePagination();
  const { sort, onSortChange } = useTableSort<MotherPickerSortKey>({ sortBy: 'createdAt', sortDir: 'desc' }, () => setPage(1));
  const [searchInput, setSearchInput] = useState('');
  const [search, setSearch] = useState('');

  // Debounce typing so each keystroke isn't a request.
  useEffect(() => {
    const t = setTimeout(() => {
      setSearch(searchInput.trim());
      setPage(1);
    }, 300);
    return () => clearTimeout(t);
  }, [searchInput, setPage]);

  const query = useQuery({
    queryKey: ['mother-picker', { search, groupId, page, limit, ...sort }],
    queryFn: () => fetchMotherPicker({ search, groupId, page, limit, ...sort }),
    placeholderData: keepPreviousData,
  });

  const toggle = (id: number) => {
    const next = new Set(selected);
    if (next.has(id)) next.delete(id);
    else next.add(id);
    onSelectedChange(next);
  };
  const pageRows = query.data?.data ?? [];
  const allOnPage = pageRows.length > 0 && pageRows.every((r) => selected.has(r.id));
  const togglePage = () => {
    const next = new Set(selected);
    for (const r of pageRows) {
      if (allOnPage) next.delete(r.id);
      else next.add(r.id);
    }
    onSelectedChange(next);
  };

  const columns: Column<MotherPickerRow, MotherPickerSortKey>[] = [
    {
      key: 'select',
      header: <input type="checkbox" aria-label="Select all on this page" checked={allOnPage} onChange={togglePage} />,
      render: (r) => (
        <input
          type="checkbox"
          aria-label={`Select ${r.name}`}
          checked={selected.has(r.id)}
          onChange={() => toggle(r.id)}
          onClick={(e) => e.stopPropagation()}
        />
      ),
    },
    { key: 'name', header: 'Name', sortKey: 'name', sortFirst: 'asc', render: (r) => r.name, width: '22%' },
    { key: 'phone', header: 'Phone', nowrap: true, render: (r) => r.phone ?? '—' },
    { key: 'bookings', header: 'Bookings', sortKey: 'completedBookings', align: 'right', render: (r) => r.completedBookings },
    { key: 'hours', header: 'Hours booked', sortKey: 'hoursBooked', align: 'right', render: (r) => r.hoursBooked },
    { key: 'spent', header: 'Total spent', sortKey: 'totalSpent', align: 'right', render: (r) => money(r.totalSpent) },
    { key: 'lastBooking', header: 'Last booking', sortKey: 'lastBookingAt', nowrap: true, render: (r) => day(r.lastBookingAt) },
    { key: 'joined', header: 'Joined', sortKey: 'createdAt', nowrap: true, render: (r) => day(r.createdAt) },
    { key: 'active', header: 'Last active', sortKey: 'lastLoginAt', nowrap: true, render: (r) => day(r.lastLoginAt) },
  ];

  return (
    <div className="mother-picker">
      <Input
        type="search"
        aria-label="Search mothers"
        placeholder="Search by name, phone or email"
        value={searchInput}
        onChange={(e) => setSearchInput(e.target.value)}
      />
      <p className="muted">{selected.size} selected · bookings, hours and spend count completed bookings</p>
      {query.isPending ? (
        <TableSkeleton />
      ) : query.isError ? (
        <ErrorState onRetry={() => void query.refetch()} />
      ) : (
        <>
          <Table
            columns={columns}
            rows={pageRows}
            rowKey={(r) => r.id}
            onRowClick={(r) => toggle(r.id)}
            sort={sort}
            onSortChange={onSortChange}
            empty={search ? 'No mothers match this search.' : 'No mothers here yet.'}
          />
          <Pagination
            page={page}
            totalPages={query.data.meta.totalPages}
            total={query.data.meta.total}
            limit={limit}
            onPageChange={setPage}
            limitOptions={ADMIN_PAGE_SIZES}
            onLimitChange={setLimit}
            label="mothers"
          />
        </>
      )}
    </div>
  );
}
```

```tsx
import type { SurveyQuestionType } from '@nanny-app/shared';
import { SURVEY_MAX_OPTIONS, SURVEY_OPTION_MAX, SURVEY_PROMPT_MAX, isChoiceQuestion } from '@nanny-app/shared';

import { Button, Field, Input } from '@admin/components/ui';

import { QUESTION_TYPE_LABEL } from './survey-labels';

export type DraftQuestion = {
  /** Client-only identity for React keys; never sent. */
  key: string;
  type: SurveyQuestionType;
  prompt: string;
  required: boolean;
  options: string[];
};

type Props = {
  question: DraftQuestion;
  index: number;
  count: number;
  onChange: (next: DraftQuestion) => void;
  onMove: (delta: -1 | 1) => void;
  onRemove: () => void;
};

const TYPES = Object.keys(QUESTION_TYPE_LABEL) as SurveyQuestionType[];

export function QuestionCard({ question, index, count, onChange, onMove, onRemove }: Props) {
  const choice = isChoiceQuestion(question.type);
  const setType = (type: SurveyQuestionType) =>
    onChange({
      ...question,
      type,
      // Switching to a choice type starts with two empty options; away from one drops them.
      options: isChoiceQuestion(type) ? (question.options.length >= 2 ? question.options : ['', '']) : [],
    });
  const setOption = (i: number, label: string) =>
    onChange({ ...question, options: question.options.map((o, j) => (j === i ? label : o)) });

  return (
    <fieldset className="question-card" aria-label={`Question ${index + 1}`}>
      <legend>Question {index + 1}</legend>
      <Field label="Question">
        <Input
          aria-label="Question"
          value={question.prompt}
          maxLength={SURVEY_PROMPT_MAX}
          onChange={(e) => onChange({ ...question, prompt: e.target.value })}
        />
      </Field>
      <Field label="Answer type">
        <select aria-label="Answer type" value={question.type} onChange={(e) => setType(e.target.value as SurveyQuestionType)}>
          {TYPES.map((t) => (
            <option key={t} value={t}>{QUESTION_TYPE_LABEL[t]}</option>
          ))}
        </select>
      </Field>
```

```tsx
import type { AdminSurvey, SurveyDraftInput } from '@nanny-app/shared';
import { SURVEY_DESCRIPTION_MAX, SURVEY_MAX_QUESTIONS, SURVEY_TITLE_MAX, SurveyDraftSchema } from '@nanny-app/shared';
import { useMutation, useQueryClient } from '@tanstack/react-query';
import { useMemo, useState } from 'react';
import { useNavigate } from 'react-router-dom';

import { Button, Card, ConfirmDialog, DetailHeader, Field, Input, useToast } from '@admin/components/ui';
import { deleteSurvey, duplicateSurvey, updateSurvey } from '@admin/lib/api';
import { errorMessage } from '@admin/lib/errors';

import { QuestionCard, type DraftQuestion } from './question-card';

let nextKey = 0;
const newKey = () => `q${nextKey++}`;

export function toDraftQuestions(survey: AdminSurvey): DraftQuestion[] {
  return survey.questions.map((q) => ({
    key: newKey(),
    type: q.type,
    prompt: q.prompt,
    required: q.required,
    options: q.options.map((o) => o.label),
  }));
}

type Props = { survey: AdminSurvey; onPublish: () => void };

export function SurveyEditor({ survey, onPublish }: Props) {
  const navigate = useNavigate();
  const toast = useToast();
  const queryClient = useQueryClient();
  const [title, setTitle] = useState(survey.title);
  const [description, setDescription] = useState(survey.description ?? '');
  const [questions, setQuestions] = useState<DraftQuestion[]>(() => toDraftQuestions(survey));
  const [dirty, setDirty] = useState(false);
  const [confirmDelete, setConfirmDelete] = useState(false);

  const draft: SurveyDraftInput = {
    title,
    description,
    questions: questions.map(({ type, prompt, required, options }) => ({ type, prompt, required, options })),
  };
  const validation = useMemo(() => SurveyDraftSchema.safeParse(draft), [title, description, questions]); // eslint-disable-line react-hooks/exhaustive-deps
  const problem = validation.success ? null : validation.error.issues[0]?.message ?? 'Check the questions';

  const touch = (fn: () => void) => {
    fn();
    setDirty(true);
  };
  const updateAt = (i: number, next: DraftQuestion) => touch(() => setQuestions((qs) => qs.map((q, j) => (j === i ? next : q))));
  const move = (i: number, delta: -1 | 1) =>
    touch(() =>
      setQuestions((qs) => {
        const next = [...qs];
        const [item] = next.splice(i, 1);
        next.splice(i + delta, 0, item!);
        return next;
      }),
    );

  const save = useMutation({
    mutationFn: () => updateSurvey(survey.id, draft),
    onSuccess: (saved) => {
      queryClient.setQueryData(['surveys', survey.id], saved);
      void queryClient.invalidateQueries({ queryKey: ['surveys'] });
      setDirty(false);
      toast.success('Draft saved');
    },
    onError: (err) => toast.error("Couldn't save", errorMessage(err)),
  });
  const duplicate = useMutation({
    mutationFn: () => duplicateSurvey(survey.id),
    onSuccess: (copy) => navigate(`/surveys/${copy.id}`),
  });
  const remove = useMutation({
    mutationFn: () => deleteSurvey(survey.id),
    onSuccess: () => {
      void queryClient.invalidateQueries({ queryKey: ['surveys'] });
      navigate('/surveys');
    },
  });

  const canPublish = !dirty && questions.length > 0 && validation.success;

  return (
    <>
      <DetailHeader
        title={title || 'Untitled survey'}
        subtitle="Draft — edit freely, then publish to send it"
        backTo="/surveys"
        backLabel="Surveys"
        actions={
          <>
            <Button variant="ghost" onClick={() => duplicate.mutate()}>Duplicate</Button>
            <Button variant="danger" onClick={() => setConfirmDelete(true)}>Delete</Button>
            <Button variant="ghost" onClick={() => save.mutate()} disabled={!dirty || !validation.success || save.isPending}>
              Save
            </Button>
            <Button onClick={onPublish} disabled={!canPublish} title={dirty ? 'Save first' : undefined}>
              Publish…
            </Button>
          </>
        }
      />
      <Card>
        <Field label="Title">
          <Input aria-label="Survey title" value={title} maxLength={SURVEY_TITLE_MAX} onChange={(e) => touch(() => setTitle(e.target.value))} />
        </Field>
        <Field label="Description" hint="Shown to mothers above the questions">
          <Input
            aria-label="Survey description"
            value={description}
            maxLength={SURVEY_DESCRIPTION_MAX}
            onChange={(e) => touch(() => setDescription(e.target.value))}
          />
        </Field>
      </Card>
      {questions.map((q, i) => (
        <QuestionCard
          key={q.key}
          question={q}
          index={i}
          count={questions.length}
          onChange={(next) => updateAt(i, next)}
          onMove={(delta) => move(i, delta)}
          onRemove={() => touch(() => setQuestions((qs) => qs.filter((_, j) => j !== i)))}
        />
      ))}
      {questions.length < SURVEY_MAX_QUESTIONS && (
        <Button
          variant="ghost"
          onClick={() => touch(() => setQuestions((qs) => [...qs, { key: newKey(), type: 'TEXT', prompt: '', required: true, options: [] }]))}
        >
          Add question
        </Button>
      )}
      {dirty && problem && <p role="alert" className="form-error">{problem}</p>}
      {confirmDelete && (
        <ConfirmDialog
          title="Delete this draft?"
          message="It has not been sent to anyone."
          confirmLabel="Delete draft"
          danger
          busy={remove.isPending}
          onConfirm={() => remove.mutate()}
          onCancel={() => setConfirmDelete(false)}
        />
      )}
    </>
  );
}
```

```tsx
import { useMutation, useQuery } from '@tanstack/react-query';
import { useState } from 'react';

import { Button, Modal, Switch, useToast } from '@admin/components/ui';
import { addSurveyRecipients, fetchUserGroups, publishSurvey } from '@admin/lib/api';
import { errorMessage } from '@admin/lib/errors';

import { MotherPickerTable } from '@admin/features/groups/mother-picker-table';

type Props = {
  surveyId: number;
  mode: 'publish' | 'add';
  onDone: (count: number) => void;
  onClose: () => void;
};

const plural = (n: number, word: string) => `${n} ${word}${n === 1 ? '' : 's'}`;

export function RecipientPickerModal({ surveyId, mode, onDone, onClose }: Props) {
  const toast = useToast();
  const [allMothers, setAllMothers] = useState(false);
  const [groupIds, setGroupIds] = useState<Set<number>>(new Set());
  const [userIds, setUserIds] = useState<Set<number>>(new Set());
  const groups = useQuery({ queryKey: ['groups'], queryFn: fetchUserGroups });

  const send = useMutation({
    mutationFn: () => {
      const target = { allMothers, groupIds: allMothers ? [] : [...groupIds], userIds: allMothers ? [] : [...userIds] };
      return mode === 'publish' ? publishSurvey(surveyId, target) : addSurveyRecipients(surveyId, target);
    },
    onSuccess: ({ count }) => {
      toast.success(mode === 'publish' ? `Sent to ${plural(count, 'mother')}` : `Added ${plural(count, 'mother')}`);
      onDone(count);
    },
    onError: (err) => toast.error("Couldn't send the survey", errorMessage(err)),
  });

  const toggleGroup = (id: number) => {
    const next = new Set(groupIds);
    if (next.has(id)) next.delete(id);
    else next.add(id);
    setGroupIds(next);
  };

  const empty = !allMothers && groupIds.size === 0 && userIds.size === 0;
  const summary = allMothers
    ? 'Every active mother will get this survey.'
    : empty
      ? 'Choose groups or mothers.'
      : `${plural(groupIds.size, 'group')} and ${plural(userIds.size, 'mother')} — anyone in both is sent it once.`;
  const action = mode === 'publish' ? 'Publish and notify' : 'Send to them';

  return (
    <Modal
      title={mode === 'publish' ? 'Publish survey' : 'Add recipients'}
      onClose={onClose}
      footer={
        <>
          <span className="muted">{summary}</span>
          <Button onClick={() => send.mutate()} disabled={empty || send.isPending}>{action}</Button>
        </>
      }
    >
      {mode === 'publish' && (
        <p className="muted">Publishing locks the questions. Each mother gets a push notification.</p>
      )}
      {mode === 'add' && <p className="muted">Mothers who already have this survey are skipped.</p>}
      <Switch checked={allMothers} onChange={setAllMothers} label="All mothers" />
      {!allMothers && (
        <>
          <fieldset>
            <legend>Groups</legend>
            {(groups.data ?? []).map((g) => (
              <label key={g.id}>
                <input
                  type="checkbox"
                  aria-label={`${g.name} (${g.memberCount})`}
                  checked={groupIds.has(g.id)}
                  onChange={() => toggleGroup(g.id)}
                />
                {g.name} ({g.memberCount})
              </label>
            ))}
            {groups.data?.length === 0 && <p className="muted">No groups yet.</p>}
          </fieldset>
          <MotherPickerTable selected={userIds} onSelectedChange={setUserIds} />
        </>
      )}
    </Modal>
  );
}
```

```ts
import { useMutation, useQuery, useQueryClient } from '@tanstack/react-query';
import type { MotherSurvey, MotherSurveySummary, SurveyAnswerInput } from '@nanny-app/shared';
import { Role } from '@nanny-app/shared';

import { api, unwrap } from '@mobile/lib/api';
import { useAuthStore } from '@mobile/store/authStore';
import { useUserProfileStore } from '@mobile/store/userProfileStore';

export const PENDING_SURVEYS_KEY = ['surveys', 'pending'] as const;
const surveyKey = (id: number) => ['surveys', id] as const;

/** Her PENDING and SKIPPED surveys — the prompt and the profile entry both read this. */
export function usePendingSurveys() {
  const firebaseUser = useAuthStore((s) => s.user);
  const role = useUserProfileStore((s) => s.profile?.role);
  return useQuery<MotherSurveySummary[]>({
    queryKey: PENDING_SURVEYS_KEY,
    enabled: !!firebaseUser && role === Role.MOTHER,
    queryFn: () => unwrap(api.get('/surveys/pending')),
  });
}

export function useSurvey(id: number) {
  return useQuery<MotherSurvey>({
    queryKey: surveyKey(id),
    enabled: Number.isFinite(id) && id > 0,
    queryFn: () => unwrap(api.get(`/surveys/${id}`)),
    retry: false,
  });
}

export function useSkipSurvey() {
  const queryClient = useQueryClient();
  return useMutation<void, Error, number>({
    mutationFn: async (id) => {
      await unwrap(api.post(`/surveys/${id}/skip`));
    },
    onSettled: () => void queryClient.invalidateQueries({ queryKey: PENDING_SURVEYS_KEY }),
  });
}

export function useSubmitSurvey(id: number) {
  const queryClient = useQueryClient();
  return useMutation<void, Error, SurveyAnswerInput[]>({
    mutationFn: async (answers) => {
      await unwrap(api.post(`/surveys/${id}/answers`, { answers }));
    },
    onSettled: () => void queryClient.invalidateQueries({ queryKey: PENDING_SURVEYS_KEY }),
  });
}
```

```tsx
            {i + 1}. {q.prompt}
            {q.required ? '' : ' (optional)'}
          </Text>
          <SurveyQuestionInput
            question={q}
            answer={answers[q.id]}
            onChange={(a) => setAnswers((prev) => ({ ...prev, [q.id]: a }))}
          />
        </View>
      ))}
      {/* Use the app's primary Button; it must expose accessibilityRole="button", label "Submit" and accessibilityState.disabled. */}
      <PrimaryButton
        label="Submit"
        disabled={problem !== null || submit.isPending}
        onPress={() => submit.mutate(given, { onSuccess: () => setDone(true) })}
      />
    </ScrollView>
  );
}
```

```ts
import type { MotherSurveySummary } from '@nanny-app/shared';

// Surveys already prompted this session — after Answer (she may back out) or
// Skip (the refetch may not have landed yet), the sheet must not reopen until
// the next launch. Cleared naturally on app relaunch (module reload), like
// ratingPromptStore's resolved set.
const prompted = new Set<number>();

export function markSurveyPrompted(id: number): void {
  prompted.add(id);
}

export function promptedSurveys(): ReadonlySet<number> {
  return prompted;
}

/** The oldest PENDING survey not prompted this session; SKIPPED ones never prompt. */
export function pickSurveyToPrompt(
  surveys: MotherSurveySummary[],
  dismissed: ReadonlySet<number>,
): MotherSurveySummary | null {
  return surveys.find((s) => s.status === 'PENDING' && !dismissed.has(s.id)) ?? null;
}
```

(A resend sets her row back to PENDING, but within the same session `prompted` still holds it — she sees the push and the profile entry; the prompt returns on next launch. That matches "prompt on next app open".)

```tsx
import React, { useEffect, useState } from 'react';
import { AppState } from 'react-native';
import { useRouter } from 'expo-router';
import { useQueryClient } from '@tanstack/react-query';
import type { MotherSurveySummary } from '@nanny-app/shared';

import SurveyPromptSheet from '@mobile/components/SurveyPromptSheet';
import { PENDING_SURVEYS_KEY, usePendingSurveys, useSkipSurvey } from '@mobile/hooks/useSurveys';
import { navigateToSurvey } from '@mobile/lib/notificationNavigation';
import { useRatingPromptStore } from '@mobile/store/ratingPromptStore';
import { markSurveyPrompted, pickSurveyToPrompt, promptedSurveys } from '@mobile/store/surveyPromptStore';

/**
 * Mount once in the parent layout. On open (and on return to the foreground)
 * offers her oldest unanswered survey with Answer / Skip. Skip keeps it in her
 * profile list; only an admin's resend brings the prompt back. The rating
 * prompt goes first when both are due.
 */
export default function SurveyPromptHost() {
  const router = useRouter();
  const queryClient = useQueryClient();
  const { data } = usePendingSurveys();
  const skip = useSkipSurvey();
  const ratingShowing = useRatingPromptStore((s) => s.booking) !== null;
  const [current, setCurrent] = useState<MotherSurveySummary | null>(null);

  useEffect(() => {
    const sub = AppState.addEventListener('change', (state) => {
      if (state === 'active') void queryClient.invalidateQueries({ queryKey: PENDING_SURVEYS_KEY });
    });
    return () => sub.remove();
  }, [queryClient]);

  useEffect(() => {
    if (current || ratingShowing || !data) return;
    setCurrent(pickSurveyToPrompt(data, promptedSurveys()));
  }, [data, current, ratingShowing]);

  if (!current || ratingShowing) return null;

  const close = () => {
    markSurveyPrompted(current.id);
    setCurrent(null);
  };
  return (
    <SurveyPromptSheet
      survey={current}
      onAnswer={() => {
        close();
        navigateToSurvey(router, current.id);
      }}
      onSkip={() => {
        skip.mutate(current.id);
        close();
      }}
    />
  );
}
```
